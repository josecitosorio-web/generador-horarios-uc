# REQUERIMIENTOS FUNCIONALES

En base a las entrevistas y reuniones realizadas con los tres usuarios, se determinaron los siguientes requerimientos funcionales:

- **RF-01:** El sistema deberá permitir al administrador registrar los cursos correspondientes a los planes de estudio de la carrera de Ingeniería de Sistemas e Informática.

- **RF-02:** El sistema deberá permitir al administrador registrar a los docentes.

- **RF-03:** El sistema deberá permitir registrar las horas de trabajo asignadas a cada docente.

- **RF-04:** El sistema deberá permitir registrar la disponibilidad horaria de los docentes.

- **RF-05:** El sistema deberá permitir registrar la cantidad de horas de dictado requeridas para cada curso, de acuerdo con su syllabus.

- **RF-06:** El sistema deberá permitir registrar los bloques horarios establecidos por la universidad.

- **RF-07:** El sistema deberá permitir registrar las aulas y ambientes disponibles para la programación.
