# REQUERIMIENTOS NO FUNCIONALES

En base a las entrevistas y reuniones realizadas, se determinaron los siguientes requerimientos no funcionales:

- **RNF-01:** El sistema deberá contar con una interfaz sencilla e intuitiva que permita al administrador registrar y gestionar la información requerida.

- **RNF-02:** El sistema deberá validar los datos ingresados para evitar información incompleta o inconsistente.

- **RNF-03:** El sistema deberá garantizar la persistencia de la información registrada en la base de datos.

- **RNF-04:** El sistema deberá mantener la integridad de las relaciones entre docentes, cursos, NRC, bloques horarios y aulas/ambientes.

- **RNF-05:** El sistema deberá contar con tiempos de respuesta adecuados para las operaciones de registro y consulta de información.

- **RNF-06:** El sistema deberá mantener un rendimiento y velocidad de respuesta similares a los establecidos en el motor de búsqueda de la primera versión de Kairos, conservando la metodología utilizada para su desarrollo.
